# Board — inherited-issues

**Opened:** 2026-10-16 · **Board:** [`IMPLEMENTATION_STATE.md`](IMPLEMENTATION_STATE.md)

This is a board with no prompts. It holds the open issues in the registry that SecondaryGWKit
(SGK) recorded while the registry was SGK's code (`RunRegistry/`), or found while adopting
`v0.1.0`, and handed to this repository on 2026-10-16 (SGK `runregistry-extraction` prompt 09,
its brief `prompts/runregistry-extraction/runregistrykit-inherited-issues-brief.md`, committed in
SGK `e96c1ea`). Each entry here is complete: the defect, the measurement, the impact and the next
step, with the package's code cited at this repository's commits. Where this repository's reading
of the code corrected the brief, the entry says so. SGK's entries stay on its boards as the record
of the original measurement; nothing here depends on reading them.

A campaign that fixes one of these issues takes it over: the entry moves to that campaign's
board's §3, and its row moves in [`docs/OPEN_ISSUES.md`](../../docs/OPEN_ISSUES.md), in the same
commit. Nothing else is done here.
